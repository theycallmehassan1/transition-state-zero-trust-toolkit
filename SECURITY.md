# Security

## Reporting a problem with these materials

This repository contains documents and templates. It does not contain running code, so the usual
vulnerability classes do not apply. The problems worth reporting are different:

- Guidance that would lead an organization to weaken a control if followed as written.
- A test case whose expected result is wrong.
- A field or instruction that would encourage someone to record sensitive data where it does not
  belong.
- A factual misstatement about NIST SP 1800-35 or any other referenced publication.

Open an issue for anything that does not itself disclose sensitive information. If the report
would require including details about a real environment, do not put them in an issue. Describe
the problem generically instead.

## Please do not put real environment data in this repository

Issues, pull requests and discussions are public. Do not include real system names, addresses,
account names, credentials, topology diagrams, scan output or exception registers from a live
environment. Anonymize first.

## Using the templates safely

A completed risk register or readiness scorecard is a description of where an organization is
weakest. Treat completed artifacts as sensitive internal documents. Store them where the rest of
your security documentation lives, control access to them, and do not commit them to a public
repository.

The blank templates here are safe to share. Your completed copies are not.
